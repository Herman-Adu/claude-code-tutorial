# Using the Calendar

The calendar view provides a time-based perspective on your tasks, helping you manage deadlines and plan your work schedule. This tutorial covers how to use the calendar effectively.

## Accessing the Calendar

Navigate to the calendar view:

1. Click **Calendar** in the sidebar navigation
2. Or use the keyboard shortcut `Ctrl/Cmd + Shift + C`
3. The calendar opens in month view by default

## Calendar Views

### Month View

The default view showing a full month:

- Tasks appear on their due dates
- Color-coded by priority
- Click any date to see all tasks
- Navigate months with arrow buttons

### Week View

A focused seven-day view:

- More detail per day
- Ideal for weekly planning
- Shows time slots if applicable
- Better for busy schedules

### Day View

Single day focus:

- Complete task list for one day
- Detailed task information
- Useful for daily planning

## Tasks on the Calendar

### How Tasks Appear

Tasks with due dates show on the calendar:

| Element | Meaning |
|---------|---------|
| Task title | Shown on the date |
| Color indicator | Priority level |
| Completion mark | Check if completed |
| Overflow indicator | "+3 more" for many tasks |

### Task Display Limits

Each calendar cell shows up to 3 tasks by default. Click "Show more" or the date to see all tasks.

## Adding Due Dates

### From the Task Form

1. Create or edit a task
2. Find the **Due Date** field
3. Click to open date picker
4. Select the date
5. Optionally set a time
6. Save the task

### From the Calendar

1. Click on a calendar date
2. Click **Add Task** or the plus icon
3. The due date is pre-filled
4. Complete the task form
5. Task appears on the calendar

## Moving Tasks by Date

### Drag and Drop

On the calendar view:

1. Click and hold a task
2. Drag to a new date
3. Release to update the due date

The task's due date updates automatically.

### Edit Due Date

1. Click the task to open details
2. Click the due date field
3. Select the new date
4. Changes save automatically

## Calendar Navigation

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Left/Right Arrow` | Previous/Next month |
| `T` | Jump to Today |
| `M` | Month view |
| `W` | Week view |
| `D` | Day view |

### Jump to Date

1. Click the date heading
2. Enter or select a date
3. Calendar navigates to that date

## Filtering Calendar Tasks

Filter what shows on the calendar:

### By Priority

Show only certain priorities:

- All priorities (default)
- High priority only
- Medium priority only
- Low priority only

### By Column/Status

Filter by task status:

- All statuses (default)
- To Do only
- In Progress only

Completed tasks can be hidden or shown.

### By Tag

Filter by task tags:

- Select one or more tags
- Only matching tasks appear

## Deadline Management

### Overdue Tasks

Tasks past their due date:

- Highlighted in red
- Appear at the top of the date
- Badge shows "Overdue"

### Upcoming Deadlines

Tasks due soon:

- Today's tasks highlighted
- Tomorrow's tasks marked
- Week view shows the upcoming timeline

### No Due Date

Tasks without due dates:

- Do not appear on the calendar
- Visible in the board view
- Consider adding dates for planning

## Calendar and Board Sync

The calendar and board are fully synchronized:

| Action | Result |
|--------|--------|
| Change date on calendar | Updates task in board |
| Change date on board | Updates calendar |
| Complete task | Completion shows on calendar |
| Delete task | Removed from calendar |

## Best Practices

### Effective Calendar Usage

1. **Set realistic dates** - Do not over-schedule
2. **Review weekly** - Adjust dates as needed
3. **Use for deadlines** - Not all tasks need dates
4. **Check daily** - Know what is due today

### Time Blocking

Use the calendar for time management:

1. Add due dates to time-sensitive tasks
2. Space tasks throughout the week
3. Avoid clustering too many on one day
4. Leave buffer time for unexpected work

> **Tip:** The calendar is a planning tool. Update dates when priorities change rather than letting tasks go overdue.

## Troubleshooting

### Tasks Not Showing

If tasks are not appearing:

1. Check if the task has a due date
2. Verify filters are not hiding it
3. Ensure you are on the correct month
4. Refresh the page

### Wrong Dates

If dates seem incorrect:

1. Check your timezone settings
2. Verify the date format matches your locale
3. Clear browser cache if issues persist
