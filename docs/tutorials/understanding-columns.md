# Understanding Columns

The Kanban board uses a three-column workflow that represents the lifecycle of your tasks. Understanding how to use each column effectively is key to maintaining an organized and productive workspace.

## The Three Columns

### To Do

The **To Do** column holds tasks that are waiting to be started:

- Tasks you have identified but have not begun
- Backlog items ready for work
- Upcoming work in your pipeline

**Best practices:**
- Keep this column focused - too many items creates noise
- Prioritize tasks so the most important are at the top
- Review regularly to remove outdated items

### In Progress

The **In Progress** column shows active work:

- Tasks you are currently working on
- Items that require your attention today
- Work that has been started but not completed

**Best practices:**
- Limit work in progress (WIP) to stay focused
- Aim for 2-3 active tasks maximum
- If a task is blocked, consider adding a tag or note

### Completed

The **Completed** column celebrates finished work:

- Tasks that are done and require no further action
- Completed work visible for reference
- Achievement tracking

**Best practices:**
- Archive old completed tasks periodically
- Review completed work to track productivity
- Use as a record of accomplishments

## Column Workflow

Tasks flow through the columns as work progresses:

```
To Do  -->  In Progress  -->  Completed
```

### Moving Tasks Between Columns

1. **Drag and Drop** - Click and drag a task card to another column
2. **Task Menu** - Click the task and select "Move to..."
3. **Quick Actions** - Use column shortcuts when available

## Work In Progress Limits

Consider setting informal WIP limits for the In Progress column:

| Team Size | Suggested WIP Limit |
|-----------|---------------------|
| Individual | 2-3 tasks |
| Small Team | 5-7 tasks |
| Large Team | 10-15 tasks |

> **Why limit WIP?** Context switching reduces productivity. Fewer active tasks means more focus and faster completion.

## Column Customization

The current implementation provides three standard columns, which align with the classic Kanban methodology:

1. **Backlog / To Do** - Work waiting to start
2. **Doing / In Progress** - Active work
3. **Done / Completed** - Finished work

## Tips for Column Management

1. **Daily Review** - Check each column at the start of your day
2. **Keep it Clean** - Move completed items and remove stale tasks
3. **Focus on Flow** - Aim to complete tasks before starting new ones
4. **Use Priorities** - Let high-priority items bubble to the top

## Visual Indicators

Each column provides visual feedback:

- **Task Count** - Shows how many tasks are in the column
- **Color Coding** - Priority colors help identify urgent items
- **Tags** - Category badges for quick filtering
