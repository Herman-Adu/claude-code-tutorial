# Creating Tasks

Tasks are the building blocks of your Kanban board. This tutorial covers everything you need to know about creating effective tasks that help you stay organized and productive.

## Opening the Task Form

There are multiple ways to create a new task:

1. Click the **Add Task** button in any column header
2. Use the keyboard shortcut `Ctrl+N` (or `Cmd+N` on Mac)
3. Click the plus icon in the floating action button

## Task Fields

When creating a task, you will see the following fields:

### Title (Required)

The task title should be clear and actionable. Good titles:

- Start with a verb (Create, Fix, Update, Review)
- Are specific about what needs to be done
- Are concise but descriptive

**Examples:**
- "Review pull request #123" (good)
- "PR" (too vague)
- "Fix navigation bug in mobile view" (good)
- "Bug" (too vague)

### Description (Optional)

Use the description field to add context:

```markdown
## Acceptance Criteria
- [ ] User can click the button
- [ ] Modal opens with correct content
- [ ] Form validation works

## Notes
See design mockup in Figma
```

### Priority Level

Choose a priority that reflects the task's urgency:

| Priority | When to Use |
|----------|-------------|
| Low | Nice-to-have tasks, can be deferred |
| Medium | Normal work items, standard priority |
| High | Urgent tasks requiring immediate attention |

### Tags (Optional)

Tags help categorize and filter your tasks:

- `bug` - Something that needs fixing
- `feature` - New functionality
- `docs` - Documentation work
- Custom tags based on your workflow

## Saving Your Task

After filling in the details:

1. Review the information you entered
2. Click the **Create Task** button
3. The task will appear in the selected column

## Task Validation

The form validates your input:

- Title is required and cannot be empty
- Title has a maximum length of 200 characters
- Description has a maximum length of 2000 characters

## Quick Task Creation

For rapid task entry when you just need to capture an idea:

1. Use the quick-add shortcut
2. Type just the title
3. Press Enter to create with default settings
4. Edit details later as needed

## Best Practices

> **Tip:** Break large tasks into smaller, actionable items. If a task takes more than a day, consider splitting it into subtasks.

1. **Be specific** - Clear titles reduce confusion
2. **Add context** - Descriptions help future-you understand the task
3. **Set appropriate priority** - Not everything is high priority
4. **Use tags consistently** - Establish a tagging convention
