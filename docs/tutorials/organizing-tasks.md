# Organizing Tasks

Effective task organization is essential for maintaining a productive workflow. This tutorial covers strategies and techniques for keeping your Kanban board well-organized.

## Organizational Strategies

### By Priority

Use priority levels to create visual hierarchy:

1. **High Priority** - Tasks requiring immediate attention
2. **Medium Priority** - Standard work items
3. **Low Priority** - Nice-to-have tasks

High-priority tasks should naturally float to the top of your attention.

### By Category

Use tags to categorize tasks by type:

- `feature` - New functionality
- `bug` - Issues to fix
- `maintenance` - Routine upkeep
- `research` - Investigation tasks

### By Project

If working on multiple projects:

- Use project-specific tags
- Consider prefixing task titles with project codes
- Leverage filters to focus on one project at a time

## Using Tags Effectively

Tags are powerful organizational tools:

```
[feature] Add user authentication
[bug] Fix login redirect issue
[docs] Update API documentation
```

### Tag Best Practices

| Do | Avoid |
|----|-------|
| Use consistent naming | Mixing cases (Bug vs bug) |
| Keep tags simple | Long, complex tag names |
| Limit tag count | Creating too many tags |
| Review tags regularly | Abandoned or unused tags |

## Filtering and Finding Tasks

The filter functionality helps you focus:

### By Priority

Click the priority filter to show only:
- All priorities
- High priority only
- Medium priority only
- Low priority only

### By Category

Filter by tag to see related tasks:
- Click a tag to filter by that category
- Combine with column view for focused work

### By Search

Use the search box to find tasks by:
- Title keywords
- Description content
- Tag names

## Reordering Tasks

Within a column, you can reorder tasks:

1. Click and hold a task card
2. Drag it up or down within the column
3. Release to set the new position

Order your tasks by importance or sequence.

## Archiving Completed Tasks

Keep your board clean by managing completed tasks:

1. Review completed tasks regularly
2. Archive old items that are no longer relevant
3. Keep recent completions visible for reference

> **Tip:** A weekly cleanup routine prevents clutter from accumulating.

## Organizational Patterns

### The Daily Review

Each morning:
1. Review In Progress - Are these still active?
2. Check To Do - What should you start today?
3. Clear Completed - Archive old items

### The Weekly Cleanup

Once a week:
1. Remove stale tasks
2. Reprioritize remaining items
3. Archive completed work
4. Review tag usage

### The Priority Matrix

Consider urgency vs importance:

|                | Urgent | Not Urgent |
|----------------|--------|------------|
| **Important**  | Do First | Schedule |
| **Not Important** | Delegate | Eliminate |

## Maintaining Organization

Long-term organization tips:

1. **Be consistent** - Use the same naming conventions
2. **Review regularly** - Keep the board current
3. **Start small** - Do not over-organize initially
4. **Iterate** - Adjust your system as needed
