# Keyboard Shortcuts

Master keyboard shortcuts to dramatically improve your productivity with the Kanban board. This tutorial covers all available shortcuts and tips for efficient keyboard-driven workflows.

## Global Shortcuts

These shortcuts work from anywhere in the application:

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + N` | Create new task |
| `Ctrl/Cmd + K` | Open command palette |
| `/` | Focus search box |
| `Escape` | Close modal / Clear selection |
| `?` | Show keyboard shortcut help |

## Navigation Shortcuts

Move around the board efficiently:

| Shortcut | Action |
|----------|--------|
| `Tab` | Move to next interactive element |
| `Shift + Tab` | Move to previous element |
| `Arrow keys` | Navigate between tasks/columns |
| `Home` | Jump to first task |
| `End` | Jump to last task |

### Column Navigation

| Shortcut | Action |
|----------|--------|
| `1` | Focus To Do column |
| `2` | Focus In Progress column |
| `3` | Focus Completed column |
| `Ctrl/Cmd + Left` | Move focus to previous column |
| `Ctrl/Cmd + Right` | Move focus to next column |

## Task Shortcuts

When a task is focused or selected:

| Shortcut | Action |
|----------|--------|
| `Enter` or `Space` | Open task detail view |
| `E` | Edit task |
| `D` | Delete task (with confirmation) |
| `P` | Change priority |
| `M` | Move task to another column |

### Quick Priority Changes

| Shortcut | Action |
|----------|--------|
| `1` (in priority mode) | Set to Low |
| `2` (in priority mode) | Set to Medium |
| `3` (in priority mode) | Set to High |

## Drag and Drop Keyboard Control

Move tasks without using the mouse:

| Shortcut | Action |
|----------|--------|
| `Space` (on task) | Pick up task for moving |
| `Arrow Up/Down` | Reorder within column |
| `Arrow Left/Right` | Move to adjacent column |
| `Space` (while moving) | Drop task at current position |
| `Escape` | Cancel move operation |

## Modal Shortcuts

When a modal is open:

| Shortcut | Action |
|----------|--------|
| `Escape` | Close modal |
| `Tab` | Move between form fields |
| `Enter` (in form) | Submit form |
| `Ctrl/Cmd + Enter` | Submit form (from any field) |

## Filter Shortcuts

Quickly adjust filters:

| Shortcut | Action |
|----------|--------|
| `F` | Open filter panel |
| `C` | Clear all filters |
| `H` | Toggle high priority filter |
| `L` | Toggle low priority filter |

## Text Editing Shortcuts

When editing task text:

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + B` | Bold text |
| `Ctrl/Cmd + I` | Italic text |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Shift + Z` | Redo |
| `Ctrl/Cmd + A` | Select all |

## Command Palette

The command palette (`Ctrl/Cmd + K`) provides quick access to any action:

1. Open with `Ctrl/Cmd + K`
2. Type to search for actions
3. Use arrow keys to select
4. Press `Enter` to execute

### Example Commands

```
> new task         - Create a new task
> filter high      - Show high priority only
> move completed   - Move selected to Completed
> settings         - Open settings
```

## Customizing Shortcuts

While custom shortcuts are not currently supported, you can:

1. Use browser extensions to remap keys
2. Request new shortcuts via feedback
3. Use the command palette for less common actions

## Accessibility Notes

All keyboard shortcuts are designed with accessibility in mind:

- Visual focus indicators show current selection
- Screen readers announce shortcut actions
- All features are keyboard-accessible
- No timing requirements for key combinations

## Learning Strategy

To master shortcuts:

1. **Start with essentials** - Learn `Ctrl+N`, `/`, and `Escape` first
2. **Add one at a time** - Practice a new shortcut daily
3. **Use the help menu** - Press `?` when you forget
4. **Practice deliberately** - Try to avoid the mouse for common tasks

> **Tip:** Keep the shortcut reference visible for the first week. Muscle memory develops quickly with practice.
